# Project Brain Semantic Pack v1.0.6

This separately versioned macOS Apple Silicon model pack contains the official
unchanged `Qwen/Qwen3-Embedding-4B-GGUF`
`Qwen3-Embedding-4B-Q6_K.gguf` artifact, a checksummed local `llama.cpp`
runtime, Apache-2.0 and runtime notices, provenance, and public/synthetic
conformance evidence.

It is not bundled into Project Brain Core or the Homebrew formula. A compatible
Core release installs only this Project Brain-controlled GitHub Release after it
checks the pinned descriptor, each part, and the final assembled GGUF. Runtime
inference is entirely local and has no Hugging Face, hosted-Qwen, or other
network dependency.

No M3 Pro performance claim, private repository/ticket result, Recall/MRR/nDCG
claim, or Precision/reranker claim is made by this pack.
