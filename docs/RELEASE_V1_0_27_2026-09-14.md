## UI 和性能范围

这一轮产品变更通过 8 个页面、3 种宽度、明暗主题共 48 组浏览器布局检查，
也检查了约 105 KB 源码结果的换行、临时 503 后恢复同一任务、页面重载、
检索期间草稿保留和防止重复提交。实际 v1.0.27 macOS 归档安装后的 UI
已完成请求分类和源码检索检查，未捕获浏览器控制台错误。

本机浏览器样本的 FCP/LCP 中位数均为 48 ms，没有超过 50 ms 的长任务；
桌面与窄屏样本最大 CLS 分别为 0.07812 和 0.00657。对 63 个实际源码文件、
约 3.38 MB 隔离副本的 60 次符号检索均找到预期定义，六类查询中位数为
321–558 ms，P95 为 373–1002 ms；冷刷新约 14.6 秒，无变更刷新中位数约 3.49 秒。
这些是本轮优化期间的本机样本，具体条件见
[此前验收记录](RELEASE_READINESS_2026-09-14.md)，不是跨设备 SLA。

真实企业仓库、目标机器模型延迟/内存和长期负载尚没有本次实测。
模型一致性通过不代表所有规模的性能问题已经解决。现有模型包、ticket 历史
及其固定源码代际继续保留；升级不需要删除数据或重装模型。
